# Campus Event Management System

The Campus Event Management System is a web-based software application designed to help students, faculty, and campus organizations discover, manage, and participate in events at Bowie State University. The purpose of the system is to create one centralized platform where users can view upcoming campus events, register for events, and receive important information about activities happening on campus. The system will also allow authorized users, such as student organization leaders and administrators, to create and manage events.

There will be three primary types of users: **students, event organizers, and administrators**. Students will be able to create an account, log into the system, browse upcoming events, search for events by category or date, view event details, and register to attend events. Event organizers will have additional permissions that allow them to create events, edit event information, view the number of registered attendees, and cancel events when necessary. Administrators will have the highest level of access and will be responsible for managing users, reviewing events, and removing inappropriate or outdated information from the system.

The software will include a graphical **user interface (UI)** that allows users to interact with the system through a web browser. The main interface will include a login and registration page, a home page displaying upcoming events, an event search page, an event details page, and a user dashboard. The dashboard will allow students to view events they have registered for and organizers to manage events they have created. Each event will display important information such as the event name, description, date, time, location, event category, organizer, and available spaces. The interface will be designed to be simple and user-friendly so that students can quickly find events without having to search through multiple university websites or social media pages.

The front end of the application will use **HTML, CSS, and JavaScript**. HTML will be used to create the structure of the webpages, CSS will control the visual design and layout, and JavaScript will provide interactive features such as event searching, filtering, form validation, and dynamically displaying information. These technologies are being selected because they are widely used for web development, are relatively easy to maintain, and provide the functionality needed to create a responsive user interface.

The back end of the application will use **Python with the Flask framework**. Flask will connect the user interface to the database and handle the application's main functionality. It will process login requests, manage user accounts, create and update events, process event registrations, and communicate with the database. Python and Flask are appropriate for this project because Python is widely used in software development and data-related applications, while Flask provides a lightweight framework that is suitable for developing a student project without unnecessary complexity.

The system will use a **MySQL relational database** to store and organize information. The database will contain tables for users, events, organizations, registrations, and event categories. Relationships between these tables will allow the system to determine which students are registered for specific events and which organizations or users created each event. For example, one student may register for multiple events, while one event may have many registered students. Using a relational database will allow information to be stored securely and retrieved efficiently whenever users access the application.

Overall, the Campus Event Management System will provide Bowie State students and organizations with a centralized way to discover and manage campus activities. The combination of a web-based UI, Python and Flask backend, and MySQL database will demonstrate important software engineering concepts such as user authentication, role-based access, database relationships, data validation, system design, and user-centered development. The system could also be expanded in the future to include email notifications, event reminders, QR-code check-ins, attendance tracking, and event feedback.
